# Logistiq Portal

Mini portail interne de suivi logistique pour environnement de démonstration de dev

## Lancement rapide

```bash
npm install
cp .env.example .env
npm start
```

L'application expose une page d'accueil sur `http://localhost:3000` et une API de statut sur `/api/status`.

## Notes

Ce dépôt contient des valeurs de développement uniquement. Les secrets et comptes de test doivent être remplacés avant toute mise en production.
